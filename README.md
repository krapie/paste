# Paste

Share text instantly with expiring links. **Live:** [paste.kevinprk.com](https://paste.kevinprk.com)

## Features

| Feature | Description |
|---------|-------------|
| **Paste & share** | Paste any text and get a shareable short link immediately |
| **Configurable TTL** | 5 min / 30 min / 1 h / 6 h / 24 h, or a custom value |
| **Countdown timer** | View page shows time remaining until expiry |
| **Dark mode** | Follows the kevinprk design system |

## Getting Started

```bash
# API (Go)
cd api && go run ./cmd/...

# Frontend (separate terminal)
cd web && npm install && npm run dev   # http://localhost:5173
```
